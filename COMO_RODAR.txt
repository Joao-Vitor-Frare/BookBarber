BOOKBARBER - COMO RODAR

ESTRUTURA:
BookBarber/
  backend/
  frontend/

BANCO:
O projeto usa PostgreSQL no Supabase. SQLite não é mais utilizado.

1) Crie um projeto no Supabase.

2) No Supabase, abra Connect e copie:
   - Transaction Pooler -> DATABASE_URL
   - Session Pooler ou Direct -> DIRECT_URL

3) Abra o Git Bash na raiz BookBarber e entre no backend:
   cd backend

4) Crie o arquivo de ambiente:
   cp .env.example .env

5) Edite .env e informe DATABASE_URL, DIRECT_URL, JWT_SECRET e dados do admin.

6) Instale:
   npm install

7) Crie as tabelas e dados iniciais no Supabase:
   npm run setup

8) Rode o backend:
   npm run start:dev

9) API local:
   http://localhost:3000/api

10) Abra frontend/index.html com Live Server/Live Preview.

LOGIN/CADASTRO:
- Cadastro: nome + telefone + e-mail + senha.
- Login: e-mail + senha.
- Conta comum: CLIENTE.
- Conta administrativa: ADMIN.

AGENDAMENTO:
- Exige login.
- Nome, telefone e e-mail são buscados da conta pelo backend.
- O modal envia apenas dados do horário/serviço/barbeiro.

DEPLOY:
- Projeto Vercel 1: Root Directory = backend
- Projeto Vercel 2: Root Directory = frontend
- No frontend publicado, configure a URL da API do backend.
- No backend publicado, configure FRONTEND_URL com a URL do frontend.

IMPORTANTE:
- Não envie backend/.env para o GitHub.
- Não envie senhas ou strings do Supabase para o GitHub.
- .vscode é configuração local do VS Code e deve ficar ignorada.
