BOOKBARBER - COMO RODAR

1) Abra o Git Bash/terminal na pasta raiz do BookBarber.

2) Entre no backend:
   cd backend

3) Na primeira vez (ou após substituir pelo ZIP novo):
   cp .env.example .env
   npm install
   npm run setup

4) Inicie o backend:
   npm run start:dev

5) Abra o frontend com o Live Server do VS Code a partir da pasta raiz do BookBarber.
   O frontend usa por padrão: http://localhost:3000/api

LOGIN:
- Página: login.html
- Contas cadastradas pelo site: perfil CLIENTE
- Admin padrão do .env.example:
  email: admin@bookbarber.com
  senha: admin123
- O painel admin.html exige login de ADMIN.

O que já está integrado:
- Cadastro/login com senha protegida e token
- Proteção das rotas administrativas
- Configuração da barbearia no banco
- Horários reais/disponibilidade
- Reserva de agendamentos
- Cliente criado/atualizado automaticamente pelo e-mail
- Escolha de serviço e barbeiro
- Produtos vindos do banco
- Admin de barbeiros, serviços, produtos e agendamentos

IMPORTANTE:
- Antes de deploy/apresentação, altere JWT_SECRET e ADMIN_PASSWORD no backend/.env.
- O arquivo backend/dev.db não deve ser enviado ao GitHub.
